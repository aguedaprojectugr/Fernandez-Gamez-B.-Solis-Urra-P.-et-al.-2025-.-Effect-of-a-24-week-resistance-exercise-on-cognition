# Materials structure
_____________________________________________________________________________________________________
The repository is organized as follows:

-At the root level of the repository:

AGUEDA_main.effect.Rproj
R project file to facilitate reproducibility and organization of the analyses.

set_of_results_all.qmd
Quarto document that compiles and displays all tables, and figures produced for the paper.

-01_data
Folder intended to store the datasets used in the analyses.

⚠️ The data are not publicly available and must be requested from the data owners.

-02_scripts
R scripts used to perform the statistical analyses and to generate all tables and figures included in the paper.

-03_outputs
Results generated by the scripts, including tables and figures outputs.

-04_supplementary
Supplementary materials associated with the manuscript.
